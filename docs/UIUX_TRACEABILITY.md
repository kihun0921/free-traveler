## 집계

| 구분 | 건수 |
|---|---:|
| 총 Requirement | 114 |
| IMPLEMENT | 92 |
| EXCLUDED | 22 |
| EXCLUDED(REQ-FUNC) | 042, 045, 055, 056, 062, 071, 072, 073, 075, 076 (10건) |
| EXCLUDED(REQ-NF) | 007, 008, 009, 010, 011, 018, 020, 021, 022, 029, 032, 033 (12건) |

이 표의 IMPLEMENT 92건은 Task 상세에서 반드시 하나 이상의 Task ID에 매핑되어야 하며, EXCLUDED 22건은 어떤 Task의 "구현 대상 Requirement"로도 등장해서는 안 된다(구현 범위 임의 복원 금지).
